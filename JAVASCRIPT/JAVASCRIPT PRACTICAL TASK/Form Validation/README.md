## 📖 Project Overview

A simple **Registration Form Validation** application built using **HTML, CSS, and JavaScript**. The application validates user inputs in real time, including name, email, password, and confirm password fields. The **Submit** button is enabled only when all inputs are valid.

────────────────────────────────────────────────────────

## ✨ Features

- Real-time form validation
- Name validation (letters only, minimum 3 characters)
- Email format validation
- Strong password validation
- Confirm password matching
- Error and success messages
- Disabled submit button until all fields are valid

 ## 📝 Validation Rules

- **Name:** Minimum 3 characters and letters only.
- **Email:** Must be in a valid email format.
- **Password:** Minimum 8 characters, including:
  - One uppercase letter
  - One lowercase letter
  - One number
  - One special character
- **Confirm Password:** Must match the password.
