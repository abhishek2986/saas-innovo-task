## 📖 Project Overview

A simple **To-Do List Application** built using **HTML, CSS, and JavaScript**. The application allows users to add, complete, undo, and delete tasks. It demonstrates DOM manipulation, event handling, and dynamic element creation using JavaScript.

────────────────────────────────────────────────────────

## ✨ Features

- Add new tasks
- Prevent adding empty tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Interactive task management
- User-friendly interface

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
