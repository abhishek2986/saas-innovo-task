## 📖 Project Overview

A simple **User List Search Application** built using **HTML, CSS, and JavaScript**. The application fetches user data from an external API and displays it in a table. Users can search for records by typing a user's name, and the table updates dynamically to show matching results.

────────────────────────────────────────────────────────

## ✨ Features

- Fetch user data from an external API
- Display users in a table
- Search users by name
- Dynamic table filtering
- Error handling for API requests

────────────────────────────────────────────────────────
