## 📖 Project Overview

A simple web application built using **HTML, CSS, and JavaScript** that fetches data from multiple APIs simultaneously using **Promise.all()**. The application displays users along with their associated todo lists and includes loading and error handling for a better user experience.
────────────────────────────────────────────────────────

## ✨ Features

- Fetch data from multiple APIs simultaneously
- Display users with their todos
- Loading indicator while fetching data
- Error handling using `try...catch`
- Uses `Promise.all()` for parallel API requests
- Displays completed and pending todos using icons
