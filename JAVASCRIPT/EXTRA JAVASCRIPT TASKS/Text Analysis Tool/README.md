## 📖 Project Overview

A simple **Text Analysis Tool** built using **HTML, CSS, and JavaScript**. The application analyzes the user-entered text by calculating the frequency of each word, the average word length, and the most common word(s). It helps demonstrate basic text processing and string manipulation techniques in JavaScript.

────────────────────────────────────────────────────────

## ✨ Features

- Analyze user-entered text
- Count the frequency of each word
- Calculate average word length
- Display the most common word(s)
- Ignore common punctuation during analysis
- Case-insensitive text processing
