## 📖 Project Overview

A simple Music Player built using HTML, CSS, and JavaScript. The application allows users to play, pause, stop, shuffle, add, and remove songs from a playlist. Users can also load songs by providing the song name, audio URL/path, and image URL. Additionally, users can play any song directly by clicking on it in the playlist, making it easy to switch between tracks.

────────────────────────────────────────────────────────

## ✨ Features

- Play selected songs
- Pause and stop music
- Shuffle playlist
- Add new songs dynamically
- Remove songs from playlist
- Display current playing song
- Show song cover image
- Interactive playlist
