## 📖 Project Overview

A simple Photo Gallery application built using **HTML, CSS, and JavaScript**. Users can add images by entering an image URL, view images in a new tab, and delete images from the gallery. The project demonstrates dynamic DOM manipulation and event handling using JavaScript.
────────────────────────────────────────────────────────

## ✨ Features

- Add image using URL
- Display images dynamically
- View image in a new tab
- Delete image from gallery
- Responsive Flexbox layout

────────────────────────────────────────────────────────
 
## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
