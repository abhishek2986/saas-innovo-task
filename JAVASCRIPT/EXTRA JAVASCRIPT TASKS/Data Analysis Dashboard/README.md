## 📖 Project Overview

A responsive **Sales Data Analysis Dashboard** built using **HTML, CSS, JavaScript, and Chart.js**. The application analyzes sales data and displays key business insights through interactive charts, summary cards, filtering options, and a searchable data table. Users can filter records by month, region, category, and product name to view real-time analytics.

────────────────────────────────────────────────────────

## ✨ Features

- Display total sales and total profit
- Calculate average sales and average profit
- Show highest and lowest sales
- Filter data by month
- Filter data by region
- Filter data by category
- Search products by name
- Reset all filters with a single click
- Display sales records in a dynamic table
- Interactive charts using Chart.js
- Responsive dashboard layout
