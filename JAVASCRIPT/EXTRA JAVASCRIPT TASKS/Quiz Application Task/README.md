## 📖 Project Overview

A simple Quiz Application built using **HTML, CSS, and JavaScript (ES6 Modules)**. The application presents multiple-choice questions one at a time, allows users to select an answer, calculates the score, and displays the final result after all questions are completed.

────────────────────────────────────────────────────────

## ⚠️ Requirement

This project uses **JavaScript ES6 Modules (`import` / `export`)**, so it **must be run using a local server** (e.g., VS Code Live Server).

────────────────────────────────────────────────────────

## ✨ Features

- Display multiple-choice questions
- Select one answer per question
- Submit answers
- Calculate and display score
- Show question progress
- Highlight selected answer
- Display final quiz result

────────────────────────────────────────────────────────
