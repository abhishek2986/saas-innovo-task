## 📖 Project Overview

A simple **Countdown Timer** built using **HTML, CSS, and JavaScript**. The application allows users to enter a time (in seconds) and start a countdown. The timer updates every second and displays an alert when the countdown is complete.

────────────────────────────────────────────────────────

## ✨ Features

- Start countdown from a user-entered value
- Display the remaining time every second
- Automatic countdown using `setInterval()`
- Stop the timer automatically using `clearInterval()`
- Display an alert when the countdown finishes
- Simple and easy-to-use interface

────────────────────────────────────────────────────────

- JavaScript (ES6)
