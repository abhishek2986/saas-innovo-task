## 📖 Project Overview

A simple **Image Carousel** built using **HTML, CSS, and JavaScript**. The application automatically cycles through a collection of images at regular intervals and allows users to navigate manually using **Previous** and **Next** buttons.

────────────────────────────────────────────────────────

## ✨ Features

- Automatic image slideshow
- Previous and Next navigation buttons
- Circular image navigation
- Auto-slide timer
- Manual navigation with timer reset
- Responsive image display

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
