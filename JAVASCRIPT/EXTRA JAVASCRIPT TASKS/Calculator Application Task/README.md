## 📖 Project Overview

A simple **Calculator Application** built using **HTML, CSS, and JavaScript**. The application allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. It also includes a reset option to clear the input fields and result.

────────────────────────────────────────────────────────

## ✨ Features

- Perform addition of two numbers
- Perform subtraction of two numbers
- Perform multiplication of two numbers
- Perform division of two numbers
- Prevent calculations when input fields are empty
- Reset input fields and result
- Simple and user-friendly interface

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
