## 📖 Project Overview

A simple **Quote of the Day** application built using **HTML, CSS, and JavaScript**. The application fetches quotes from a public API and displays a random quote with its author whenever the user clicks the button.

────────────────────────────────────────────────────────

## ✨ Features

- Fetch quotes from an API
- Display a random quote
- Show quote author
- Button to generate a new random quote
- Error handling for failed API requests

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
