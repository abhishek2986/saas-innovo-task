## 📖 Project Overview

A simple **To-Do List** application built using **HTML, CSS, and JavaScript**. Users can add tasks and rearrange them using drag-and-drop functionality. The project demonstrates DOM manipulation, drag-and-drop events, and dynamic task management.

────────────────────────────────────────────────────────

## ✨ Features

- Add new tasks
- Drag and drop tasks
- Reorder tasks dynamically
- Update task order in the array
- Dynamic task rendering
- Simple and responsive interface

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
