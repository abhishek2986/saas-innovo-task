## 📖 Project Overview

A simple **Guess the Number Game** built using **HTML, CSS, and JavaScript**. The player enters a number to guess a randomly generated number. The game provides hints whether the guess is too high or too low, tracks the number of attempts, and deducts **10 points after every three attempts**.

────────────────────────────────────────────────────────

## ✨ Features

- Random number generation
- User number input
- High/Low hints
- Score tracking
- Attempt counter
- 10-point deduction after every 3 attempts
- Display final score when guessed correctly

## 🎮 Game Rules

- Initial score: **100**
- Every **3 attempts**, **10 points** are deducted.
- The game displays:
  - Hint (Too High / Too Low)
  - Current Score
  - Number of Attempts
- The game ends when the correct number is guessed.
