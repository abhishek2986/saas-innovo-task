## 📖 Project Overview

A simple **Recipe Management System** built using **HTML, CSS, and JavaScript**. The application allows users to add, edit, delete, search, and filter recipes. All recipe data is stored in the browser using **Local Storage**, ensuring recipes remain available even after refreshing the page.

────────────────────────────────────────────────────────

## ✨ Features

- Add new recipes
- Edit existing recipes
- Delete recipes
- Search recipes by ingredient
- Filter recipes by category
- Store recipes using Local Storage
- Dynamic recipe list updates

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
