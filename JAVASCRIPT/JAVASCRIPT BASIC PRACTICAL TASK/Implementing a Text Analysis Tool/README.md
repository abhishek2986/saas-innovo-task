## 📖 Project Overview

A simple **Text Analysis Tool** built using **HTML, CSS, and JavaScript**. The application analyzes user-entered text by calculating the total number of characters, total number of words, and the frequency of each unique word. It also ignores punctuation and treats words in a case-insensitive manner for accurate analysis.

────────────────────────────────────────────────────────

## ✨ Features

- Count total characters
- Count total words
- Display frequency of each unique word
- Ignore punctuation during analysis
- Case-insensitive text processing
- Dynamic result display
