## 📖 Project Overview

A simple **Task Manager Application** built using **HTML, CSS, and JavaScript**. The application allows users to add, edit, delete, and manage tasks with completion status. Tasks are stored in **Local Storage**, so they remain available even after refreshing the page.

────────────────────────────────────────────────────────

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete or incomplete
- Filter tasks by status
- Store tasks using Local Storage
- Dynamic task list updates

────────────────────────────────────────────────────────

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
